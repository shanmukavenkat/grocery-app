# శ్రీరామ & పూజా స్టోర్ (Sri Ram Kirana & Pooja Store)
## భారతీయ కిరాణా, కూరగాయలు, పండ్లు & పవిత్ర పూజా సామాగ్రి ఆర్డరింగ్ & 80mm థర్మల్ రసీదు PDF వెబ్ అప్లికేషన్

భారతీయ కిరాణా సరుకులు, తాజా కూరగాయలు, పండ్లు మరియు హిందూ పూజా సామాగ్రిని పూర్తి తెలుగు పేర్లు, తెలుగు కొలతలు మరియు **NRIOL అసలైన ఉత్పత్తుల ఫోటోలతో** ఎంచుకుని, దుకాణం శైలిలో **80mm థర్మల్ రసీదు (Ticket-Style Receipt) లేదా PDF** గా మార్చే ఆధునిక వెబ్ అప్లికేషన్.

### 3. దుకాణం శైలి 80mm థర్మల్ రసీదు (Ticket-Style Thermal Receipt & PDF)
- **80mm రసీదు కొలతలు:** సూపర్ మార్కెట్ మరియు కిరాణా దుకాణాల థర్మల్ ప్రింటర్ సైజులో రసీదు డిజైన్.
- **భక్తిపూర్వక శీర్షిక:** `|| శ్రీరస్తు - శుభమస్తు ||` తో ప్రారంభం.
- **వస్తువుల విభజన:** రసీదులో సరుకులు విడివిడిగా గ్రూప్ చేయబడతాయి:
  - `*** [ కిరాణా సరుకులు & పప్పులు ] ***`
  - `*** [ తాజా కూరగాయలు & ఆకులు ] ***`
  - `*** [ తాజా పండ్లు ] ***`
  - `*** [ పవిత్ర హిందూ పూజా సామాగ్రి ] ***`
  *(పూజా సామాగ్రిని ఉల్లిపాయలు, వెల్లుల్లితో కలపకుండా ప్రత్యేక పవిత్ర సంచిలో భక్తిశ్రద్ధలతో ప్యాక్ చేయడానికి ప్రత్యేక సూచన ఉంటుంది!)*
- **సహజమైన రసీదు అంశాలు:** రసీదు నంబర్ (#KC-1042), తేదీ & సమయం, వినియోగదారుని వివరాలు, పరిమాణం, మొత్తం బిల్లు, బార్‌కోడ్ గ్రాఫిక్ మరియు `ధన్యవాదములు - మళ్ళీ దర్శించండి`.
- **ప్రింట్ & PDF:** సింగిల్ క్లిక్‌తో బ్రౌజర్ ద్వారా నేరుగా ప్రింట్ చేయవచ్చు లేదా అధిక నాణ్యత గల తెలుగు లిపి PDF గా డౌన్‌లోడ్ చేసుకోవచ్చు.

### 4. కార్డ్ ఓవర్‌ఫ్లో పరిష్కారం - హోవర్ కలర్ చుక్కలు (Priority Dots with Tooltip)
- కార్డుల్లోంచి బయటకు పొడుచుకువచ్చే "ముఖ్యమైనది" వంటి పెద్ద బ్యాడ్జీల స్థానంలో అందమైన కలర్ చుక్కలను ఏర్పాటు చేశాము.
  - 🟡 **అంబర్ చుక్క:** ముఖ్యమైన సరుకు (Essential)
  - 🟢 **ఆకుపచ్చ చుక్క:** తాజా పంట (Fresh Farm)
  - 🔴 **గులాబీ చుక్క:** ప్రత్యేక ఆఫర్ (Special Offer)
  - 🟠 **నారింజ చుక్క:** పూజా విశేషం (Sacred Pooja)
- చుక్కపై మౌస్ ఉంచినప్పుడు (Hover) లేదా తాకినప్పుడు (Tap) చిన్న టూల్‌టిప్ ప్రత్యక్షమవుతుంది. కార్డులు ఏ పరికరంలోనైనా అందంగా సరిపోతాయి.

## 🚀 అప్లికేషన్‌ను ప్రారంభించే విధానం (How to Run Locally)

1. ఫోల్డర్‌లోని `start.bat` ఫైల్‌పై డబుల్ క్లిక్ చేయండి.
2. లోకల్ సర్వర్ ప్రారంభమై మీ బ్రౌజర్‌లో `http://localhost:8080/index.html` ఆటోమేటిక్‌గా ఓపెన్ అవుతుంది.
3. లేదా నేరుగా `index.html` ఫైల్‌పై డబుల్ క్లిక్ చేసి కూడా బ్రౌజర్‌లో ఉపయోగించవచ్చు!

## 🌐 GitHub లో పబ్లిష్ చేసి పబ్లిక్ లింక్ పొందే విధానం (Publish to GitHub Pages)

1. [GitHub New Repository](https://github.com/new) పేజీకి వెళ్లి కొత్త రిపోజిటరీని సృష్టించండి (ఉదా: `telugu-grocery-app`, Public గా ఎంచుకోండి).
2. ఫోల్డర్‌లోని `publish-to-github.bat` ఫైల్‌పై డబుల్ క్లిక్ చేయండి.
3. మీ రిపోజిటరీ లింక్ (URL) ఎంటర్ చేయండి.
4. కోడ్ ఆటోమేటిక్‌గా GitHub కు అప్‌లోడ్ అవుతుంది.
5. GitHub లో మీ రిపోజిటరీ **Settings -> Pages** కు వెళ్లి, Branch ను `main` గా ఎంచుకుని **Save** క్లిక్ చేయండి.
6. 1-2 నిమిషాల్లో మీ ఉచిత పబ్లిక్ లింక్ సిద్ధమవుతుంది: `https://<your-username>.github.io/telugu-grocery-app/`!
